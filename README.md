# Learning When a Robot Should Ask for Help

Project page for **Learning When a Robot Should Ask for Help: Adaptive Intervention Requests in Human–Robot Teaming**.

Website: <https://human-robot-teaming.github.io/>

This is a dependency-free static site. Preview it locally from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
